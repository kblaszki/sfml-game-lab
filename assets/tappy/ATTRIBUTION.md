# Tappy art attribution

`atlas.png` currently ships **procedural stand-in** sprites (sky, hills, plane, rock gates) so the game runs with `SpriteBank` without vendoring a large pack.

**Intended art (replace when convenient):** [Kenney Tappy Plane](https://kenney.nl/assets/tappy-plane) by Kenney Vleugels — [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Credit (optional): Kenney.nl.

Region names in `atlas.txt` match the planned Kenney crops (`bg/sky`, `bg/hills`, `player/blue`, `gate/rockTop`, `gate/rockBottom`) so swapping files keeps the same manifest names.
